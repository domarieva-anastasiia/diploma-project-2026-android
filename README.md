# SRGAN Android Client (diploma project 2026)

Мобільний застосунок на базі ОС Android, що виконує роль клієнтської частини у програмному комплексі для покращення роздільної здатності зображень. 
Застосунок спроєктовано за принципом «тонкого клієнта», він повністю звільняє мобільний пристрій від важких нейромережевих обчислень.
Усі ресурсомісткі операції (робота з моделлю SRGAN та попередня обробка вхідних даних) делегуються віддаленому Flask-серверу, тоді як застосунок забезпечує зручний інтерфейс користувача,
роботу з камерою/галереєю та асинхронний моніторинг процесу генерації.

## Основний функціонал

* **Імпорт зображень:** можливість завантажити фото з галереї пристрою або зробити знімок через вбудовану камеру.
* **Асинхронний моніторинг:** відправка файлів на сервер у фоновому потоці без блокування інтерфейсу (використано OkHttp3).
* **Механізм Polling:** циклічне опитування сервера кожні 2 секунди з динамічним відображенням прогресу обробки (від 1% до 100%) на екрані завантаження.
* **Інтерактивне порівняння:** унікальний екран результатів із рухомим слайдером «До/Після» для попіксельної оцінки якості роботи нейромережі.
* **Адаптивний експорт:** збереження готових PNG-зображень у галерею пристрою з урахуванням вимог безпеки.

## Технологічний стек

* **Мова програмування:** Kotlin
* **Середовище розробки (IDE):** Android Studio
* **Мінімальна версія ОС (Min SDK):** API 26 (Android 8.0)
* **Цільова версія ОС (Target SDK):** API 34 (Android 14)
* **Мережева взаємодія:** OkHttp3 (з розширеними таймаутами для обробки великих файлів)
* **Парсинг даних:** JSONObject

## Інструкція із запуску проєкту

Для успішного запуску та тестування мобільного застосунку на локальному комп'ютері або фізичному пристрої виконайте наступні кроки:

### 1. Попередні вимоги
Переконайтеся, що на вашому комп'ютері встановлено актуальну версію **Android Studio** та встановлено **Android SDK** для API 34.

### 2. Клонування репозиторію
Склонуйте цей репозиторій на свій локальний комп'ютер за допомогою Git:
```bash
git clone https://github.com/domarieva-anastasiia/diploma-project-2026-android.git
```

### 3. Імпорт проєкту в Android Studio  
Відкрийте Android Studio. Оберіть пункт File -> New -> Import Project. Вкажіть шлях до кореневої папки склонованого проєкту та натисніть OK.
Зачекайте, поки відбудеться первинна синхронізація проєкту з системою збірки Gradle.

### 4. Конфігурація адреси сервера  
За замовчуванням застосунок налаштований на роботу з хмарним сервером, розгорнутим на платформі Railway.
Якщо ви бажаєте змінити адресу або протестувати сервер локально, виконайте наступні дії:  
Відкрийте файл ProcessingActivity.kt та MainActivity.kt.  
Знайдіть URL-адресу сервера: https://srgan-domarieva.up.railway.app/.  
Змініть її на власну хмарну адресу або локальну ip-адресу Вашого комп'ютера у локальній мережі (наприклад http://192.168.X.X:5000/).  

### 5. Запуск застосунку
Підключіть фізичний Android-смартфон через USB-кабель (із увімкненим «Режимом розробника» та «Налагодженням по USB»)
або запустіть віртуальний емулятор в Android Studio Device Manager.  
Натисніть кнопку Run на верхній панелі інструментів Android Studio.  
Після успішної збірки застосунок автоматично інсталюється та запуститься на вашому пристрої.

## Важливе зауваження щодо обмежень обробки  
Поточна версія нейромережі на сервері має апаратне обмеження оперативної пам'яті. Обробка зображень із роздільною здатністю понад 2000х2000 пікселів може
призвести до помилки сервера Out of Memory.
Рекомендується завантажувати для тестування фотографії середнього або низького розміру.
